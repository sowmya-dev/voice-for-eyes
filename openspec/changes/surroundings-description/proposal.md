# Proposal: surroundings-description

## Why
Users want to know what is around them, which needs the optional cloud service.

## What Changes
- Room description with follow-up questions when cloud is available.
- A fixed spoken reply when it is not.

## Capabilities

### New Capabilities
- `surroundings-description`: see [`specs/surroundings-description/spec.md`](specs/surroundings-description/spec.md).

### Modified Capabilities
None.
