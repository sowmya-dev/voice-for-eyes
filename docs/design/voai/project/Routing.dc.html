How VoAI picks the next screen

The voice layer, not a button, decides where the user goes. The screen only follows what was said and what the camera could read.

Gate: “back”, “next” and “settings” are accepted only when the current task is finished. If it isn’t, VoAI says why and returns to the start, then waits for the user’s question.
