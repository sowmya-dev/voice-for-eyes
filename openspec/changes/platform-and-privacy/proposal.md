# Proposal: platform-and-privacy

## Why
The app must run for the judges with one command, work on basic phones and keep user data private.

## What Changes
- Web client served by Docker on port 3000, without keys.
- On-device speech and OCR, offline use, local logging and performance checks.

## Capabilities

### New Capabilities
- `platform-and-privacy`: see [`specs/platform-and-privacy/spec.md`](specs/platform-and-privacy/spec.md).

### Modified Capabilities
None.

New behaviour; no archived specs are affected. Source mapping: [`openspec/traceability.md`](../../traceability.md).
