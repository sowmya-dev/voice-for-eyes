# Proposal: voice-interaction

## Why
A blind user must run the whole assistant by voice, from opening the app to interrupting an answer.

## What Changes
- Automatic start of camera and listening, with continuous listening and mute.
- Interruption, uninterrupted capture and torch control.
- Keyword intent routing and the single interaction pipeline.

## Capabilities

### New Capabilities
- `voice-interaction`: see [`specs/voice-interaction/spec.md`](specs/voice-interaction/spec.md).

### Modified Capabilities
None.

## Impact
New behaviour; no archived specs are affected. Source mapping: [`openspec/traceability.md`](../../traceability.md).
